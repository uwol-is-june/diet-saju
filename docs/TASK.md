# 개발 순서

## 1. [TASK-29] 맨 위로 가는 플로팅 버튼 · **(S)** · ⬜ 대기

결과를 다 읽고 폼으로 돌아가려면 스크롤이 오래 걸린다. **우측 하단에 고정된 "맨 위로"
버튼**을 만든다.

**지금 화면이 얼마나 긴가**: 원국 카드 + 기운의 관계(도식 둘) + 대운·세운 + 풀이 8절
(TASK-28 로 문장마다 문단이라 세로가 더 늘었다) + 공유 카드. 1280px 에서도 여러 화면 분량이다.

**놓을 자리**: `app/layout.tsx` 의 `<body>` — `{children}` · `SiteFooter` 옆. `app/page.tsx` 는
서버 컴포넌트라 스크롤 상태를 들 수 없으므로 버튼은 `"use client"` 로 만든다. layout 에 두면
`/disclaimer`·`/privacy` 에서도 함께 동작한다 (그 편이 맞다).

### 먼저 알아야 할 함정

- **`behavior: "smooth"` 를 명시하면 CSS `scroll-behavior` 가 무시된다.** 그래서 모션 최소화
  대응을 CSS 에 맡길 수 없고 JS 에서 직접 분기해야 한다. `SajuForm` 의 자동 스크롤이 이미
  `window.matchMedia("(prefers-reduced-motion: reduce)")` 로 같은 판단을 하고 있으니
  **그 코드를 그대로 따를 것.**
- **결과 도착 시 자동 스크롤과 싸우지 않게 한다.** `SajuForm` 은 `chart` 가 바뀔 때 결과로
  내려보낸다. `chart` 는 요청당 한 번만 바뀌므로 충돌하지 않을 것으로 보이지만,
  **맨 위로 올라간 직후 다시 끌려 내려가지 않는지 실제로 확인할 것.**
- **채운 버튼이므로 `bg-brand-solid` + `text-on-brand-solid` 다** (TASK-21).
  `bg-brand`(연한 초록) 위에 흰 아이콘을 올리면 1.82:1 로 AA 미달이다.
- **`focus:ring-*` 을 붙이지 말 것.** 포커스 링은 `globals.css` 의 전역 `:focus-visible`
  하나로 정한다. 컴포넌트에 `outline-none` 을 쓰면 그 전역 규칙이 조용히 덮인다.
- **새 키프레임을 만들면 `from` 만 써야 한다** (TASK-25). `lib/design/motion.test.ts` 가
  모든 키프레임에 `to`/`100%` 가 없는지 검사한다 — 모션 최소화 설정에서 숨은 상태에 갇히는
  것을 막는 규칙이다. 그래서 **등장은 애니메이션할 수 있어도 퇴장은 안 된다**(사라질 때는
  요소 자체가 없어지므로). 나타났다 사라지는 버튼에 이 규칙을 어떻게 맞출지 정하고 근거를 남길 것.

### 작업

- [ ] `components/ScrollToTop.tsx`(클라이언트) 추가하고 `app/layout.tsx` 에 배치
- [ ] **언제 보일지 정한다.** 첫 화면(폼만 있는 상태)에서는 보이지 않아야 한다.
      `scroll` 리스너를 쓰면 `{ passive: true }` + rAF 스로틀, 아니면 상단에 감시용 요소를 두고
      `IntersectionObserver` (이쪽이 더 싸다)
- [ ] 모션 최소화 분기 — 위 함정대로 `matchMedia` 로 `behavior` 를 고른다
- [ ] **접근성**: `aria-label="맨 위로"`, 터치 타깃 44px(`min-h-11`/`min-w-11`).
      맨 위로 이동한 뒤 **키보드 포커스가 화면 밖 버튼에 남지 않게** 처리 방식을 정할 것
      (상단 요소로 포커스를 옮길지, 스크롤만 하고 둘지 — 정하고 이유를 주석에 남긴다)
- [ ] **겹침 확인**: 하단 고정이라 `SiteFooter`·공유 버튼과 겹칠 수 있다.
      iOS 홈 인디케이터도 피할 것 (`env(safe-area-inset-bottom)`)
- [ ] 색·아이콘에 raw hex 를 쓰지 않는다. `lib/design/tokens.test.ts` 의 검사 목록에
      새 컴포넌트를 **추가**할 것 — 목록에 없으면 검사되지 않는다
- [ ] 390·1280px 실측 — 버튼이 본문을 가리지 않는지, 가로 스크롤이 생기지 않는지

→ 완료 기준: 결과 화면 아래쪽에서 버튼이 보이고 눌러서 맨 위로 이동하며, 모션 최소화
설정에서는 애니메이션 없이 즉시 이동한다. 세 폭 모두에서 다른 요소와 겹치지 않는다.
