## 1. [TASK-28] 문장 단위 줄바꿈으로 가독성 개선 · **(S)** · ⬜ 대기

**먼저 하는 이유**: 본문 렌더 자체를 바꾸므로 **내용이 다 들어온 뒤**(TASK-24·27 완료)
하는 것이 맞고, 2(도식화)가 얹힐 바탕이므로 그보다는 앞이다. 세 유형 전부에 영향을 준다.

지금 풀이 본문이 한 문단에 여러 문장이 붙어 나와 벽처럼 읽힌다. 마침표 단위로 끊어 달라는 요청.

**함정: 프롬프트만 고쳐서는 안 된다.** `react-markdown` 은 CommonMark 라 **단일 개행을
줄바꿈으로 렌더하지 않는다** (`remark-breaks` 등 플러그인 없음 — `package.json` 확인).
모델이 문장마다 개행해도 화면에서는 공백 하나로 붙는다.

- [ ] 방식 결정 — ① `remark-breaks` 추가 + 프롬프트에서 문장마다 개행 ② 렌더 직전 문자열
      후처리로 마침표 뒤 개행 삽입 ③ 빈 줄로 문단을 자주 나누라고만 지시(플러그인 불필요,
      지금도 동작하지만 문단 간격이 커진다)
- [ ] ②를 고르면 **마침표가 문장 끝이 아닌 경우**를 전부 막는다 — `3.5kg` 같은 소수점,
      `1. 항목` 순서 목록, 영문 약어. 목록 줄(`- `)과 제목 줄에는 적용하지 않는다
- [ ] **스트리밍 중에 줄이 튀지 않아야 한다.** 파서는 누적 문자열을 매 조각 다시 파싱하므로
      후처리도 매번 다시 돈다. 마지막 문장이 잘려 오는 동안 커서 앞에서 줄이 접혔다 펴지는지 확인
- [ ] **폴백 경로에도 같은 처리를 건다** — `recognized === false` 일 때 원문 마크다운을 그대로
      그리는 분기(`ReadingSections.tsx`)가 따로 있다. 한쪽만 고치면 화면이 갈린다
- [ ] `.reading p` 의 여백을 다시 본다 (`globals.css`: `line-height: 1.75`,
      `margin-bottom: 0.75rem`). 문장마다 끊으면 리듬이 달라져 지금 값이 안 맞을 수 있다
- [ ] **모바일 폭에서 실측** — 한 문장이 한 줄에 안 들어가면 문장 단위 개행이 오히려
      들쭉날쭉해 보인다. 390px 에서 확인하고 안 되면 문단 단위로 물러설 것
- [ ] 공유 카드(`lib/share/draw-card.ts`)는 캔버스에서 자체 줄바꿈을 한다 — 원문 개행이
      늘 때 카드 레이아웃이 깨지지 않는지 확인
- [ ] 섹션 제목·요약 카드는 그대로 둔다 (`.reading` 은 본문에만 붙는 규칙 유지)

→ 완료 기준: 390px·1280px 양쪽에서 문장이 시각적으로 구분되고, 스트리밍 중 줄이 튀지 않으며,
소수점·순서 목록이 깨지지 않는다.

## 2. [TASK-25] 도식화와 애니메이션 · **(O)** · ⬜ 대기

**마지막인 이유**: 위 것들이 레이아웃과 내용을 바꾼다. 지금 그림을 얹으면 곧 고칠 것 위에
그리게 된다. 대신 **작업량이 가장 크고 사용자가 중요하다고 말한 항목**이라, 착수하면
범위를 먼저 좁혀 한 덩어리씩 낼 것.

지금 결과 화면은 숫자와 글자뿐이다. 사주는 관계(상생·상극)와 흐름(대운·세운)이 핵심인데
둘 다 그림이 훨씬 잘 전달한다.

- [ ] 범위 결정 — 후보: ① 오행 상생·상극 오각형(관계도) ② 오행 분포 차트 ③ 대운 타임라인
      ④ 한열 눈금(−2~+2) ⑤ 섹션이 도착할 때의 등장 트랜지션
      **한 번에 다 하지 말고 우선순위를 정할 것**
- [ ] 차트 라이브러리를 넣지 않고 **인라인 SVG** 로 구현하는 방향을 먼저 검토
      (번들 비용 + 색을 CSS 토큰에서 읽어야 하는 제약)
- [ ] 색은 시맨틱 토큰만 쓴다. `lib/design/tokens.test.ts` 가 컴포넌트의 raw hex 를 막으므로
      새 컴포넌트를 그 검사 목록에 추가할 것
- [ ] **애니메이션은 `prefers-reduced-motion` 을 존중한다** — `app/globals.css` 에 전역 규칙이
      이미 있으니 그것으로 꺼지는지 확인하고, 안 꺼지는 방식(JS 애니메이션)을 쓰면 직접 분기
- [ ] **스트리밍과 싸우지 않게 한다.** 섹션은 도착하는 대로 렌더된다 — 등장 애니메이션이
      매 조각마다 재생되면 글이 떨리게 보인다. 섹션이 `complete` 될 때 한 번만 재생할 것
- [ ] 공유 카드(`lib/share/draw-card.ts`)와 시각 언어를 맞춘다. 화면과 카드가 달라 보이면 어색하다
- [ ] 다크 모드는 도입하지 않는다 (확정 사항). 밝은 톤 하나만 맞추면 된다
- [ ] 실기 확인 — 모바일 폭에서 도식이 잘리지 않는지, 가로 스크롤이 생기지 않는지

→ 완료 기준: 원국과 대운을 글자 없이도 읽을 수 있고, 모션 최소화 설정에서 정지 상태로 보인다.

## 3. [TASK-26] 파비콘·앱 아이콘 추가 · **(H)** · ⬜ 대기

**요청받은 항목이 아니다** — TASK-10 배포 검증 중에 발견해 적어 둔다. 우선순위는 낮다.

`/favicon.ico`, `/icon.png`, `/apple-touch-icon.png` 가 모두 404 이고 `app/` 에 아이콘 파일이
없다. 브라우저 탭·카카오톡 공유·홈 화면 추가에서 기본 아이콘으로 뜬다.

- [ ] `app/icon.png` (또는 `icon.svg`) 추가 — Next 가 자동으로 메타 태그를 붙인다
- [ ] `app/apple-icon.png` 추가 (홈 화면 추가용)
- [ ] og 카드(`docs/og-card.html`)와 같은 시각 언어로 만들 것

→ 완료 기준: 세 경로가 404 를 내지 않고 탭에 아이콘이 보인다.
