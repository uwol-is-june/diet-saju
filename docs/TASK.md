### 끝낸 것에서 남는 규칙

같은 결정을 다시 하지 않도록 **결론이 사는 곳**만 적어 둔다. 태스크 본문은 지웠다.

| 무엇 | 결론이 사는 곳 |
| --- | --- |
| 풀이 서술 품질 측정 도구·기준선 | `docs/saju-validation.md` 3-6 절 · `scripts/sample-readings.mjs` |
| 추론 예산 (`thinkingLevel`) | `CLAUDE.md` "LLM 취급" · `lib/gemini.ts` 주석 |
| hedge 경계 · 절 구성 · 말투 | `CLAUDE.md` "판정은 단정…" · "분량은 절마다…" · "말투는 리포트가…" |
| 유형 여섯 (공개 다섯) | `CLAUDE.md` "확정된 결정사항" |
| 대운·종목 판정과 우리 관례 | `docs/saju-validation.md` 3-3-1 · 3-4-1 절 |
| 계약 제목은 재현하기 쉬운 낱말로 | `CLAUDE.md` "계약 제목은…" (`움직-` 어간 실측) |
| Motion 도입 조사 | `CLAUDE.md` "보류한 작업 > 애니메이션 라이브러리" |

**측정이 필요한 변경을 할 때는 고치기 전에 기준선을 다시 찍지 말고** 3-6 절 표를 기준으로
삼는다 — 같은 표를 두 번 만들면 어느 쪽이 기준인지 갈린다. 고친 뒤에 `--label after --repeat 2`.

### 배포 뒤 한 번 확인할 것

- **프로덕션 응답 시간.** 분량이 두 배가 되고 유형이 여섯으로 늘어난 뒤로 프로덕션에서 잰
  적이 없다. 로컬은 유형별 6~10초이고 `maxDuration = 30` 이다. 표본 하나가 133초까지 간
  적이 있는데(로컬 네트워크 지연) 그 종류의 지연은 모든 유형이 함께 진다.
