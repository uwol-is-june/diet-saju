# 디자인 토큰 — 컬러 팔레트

팔레트의 **출처와 선택 근거**를 남긴 문서다. 적용된 값의 기준은 `app/globals.css` 이고,
대비비는 `lib/design/tokens.test.ts` 가 그 파일을 파싱해 검증한다.
색을 바꿀 때는 globals.css 1층(`--raw-*`)을 고치고 이 문서의 근거도 갱신한다.

## 출처

[web.dasii.kr](https://web.dasii.kr/) — "다시 · 다이어트 보조제 성분 분석 및 후기 서비스".
Next.js + Tailwind v4 앱이라 CSS 번들(`/_next/static/chunks/*.css`)의 `@theme` 토큰을
그대로 읽었다. 추출 시점: 2026-08-12. 스크린샷 샘플링이 아니라 원본 토큰값이다.

## 브랜드 토큰

Tailwind 기본 스케일과 이름이 다른(하이픈 없는 `green500` 형태) 것들이 이 서비스가
직접 정의한 값이다. 키컬러는 **그린**이고, 블루는 링크/보조, 레드는 에러 전용이다.

### 그린 (primary)

| 토큰 | HEX | 용도 (사이트 관찰) |
| --- | --- | --- |
| `green50` | `#EAFAF2` | 배지·강조 블록 배경 |
| `green100` | `#D5F6E4` | 테두리, 연한 구분선 |
| `green500` | `#50D88F` | 키컬러. 버튼·활성 상태 |
| `green600` | `#25A762` | hover/press, 그린 위 텍스트 |

`green500` 은 밝아서 흰 텍스트 대비가 부족하다(대비비 약 1.9:1).
버튼 라벨은 `green600` 배경이나 어두운 잉크색을 써야 WCAG AA 를 넘긴다.

### 보조 색

| 토큰 | HEX | 용도 |
| --- | --- | --- |
| `blue500` | `#3385FF` | 링크, 정보성 강조 |
| `red` | `#FF3A4A` | 에러·경고 |
| `star-yellow` | `#F6C72B` | 별점 아이콘 |
| `gray-box` | `#F6F5FA` | 카드/섹션 배경 (살짝 보라 기운) |

### 뉴트럴 스케일

Tailwind 기본 그레이가 아니라 별도 정의된 스케일이다. 중간톤(`gray500`)이
약간 따뜻하고, 어두운 쪽은 중성에 가깝다.

| 토큰 | HEX |
| --- | --- |
| `gray50` | `#F1F2F3` |
| `gray100` | `#E4E6E7` |
| `gray200` | `#C9CCCF` |
| `gray300` | `#AEB3B7` |
| `gray400` | `#939A9F` |
| `gray500` | `#6D676C` |
| `gray700` | `#363A3D` |
| `gray800` | `#303336` |
| `gray900` | `#181A1B` |

`gray600` 은 원본에 정의되어 있지 않다. 필요하면 `#4A4E52` 정도로 보간한다.

### 페이지 배경 그라디언트

`bg-gradient-to-b from-[#FDFFFB] to-[#F5FDFE]` — 위(따뜻한 화이트) → 아래(찬 민트 화이트).
거의 흰색이라 단색으로 대체해도 시각차가 거의 없다. 히어로 영역에만 쓰는 것을 권장.

## 적용 결과 (TASK-16 완료, 2026-08-13)

서비스 정체성이 "두 유형 유지 + 브랜드는 그린"으로 확정되어 이 팔레트를 도입했다.
기존 보라색(`#7c3aed`) + 종이질감 뉴트럴은 제거됐다.

### 원본을 그대로 쓸 수 없었던 이유

**출처 팔레트에 접근성 문제가 있었다.** 실측한 대비비:

| 조합 | 대비비 | AA(4.5:1) |
| --- | --- | --- |
| `green500` + 흰 텍스트 | 1.82:1 | ❌ |
| `green600` + 흰 텍스트 | 3.10:1 | ❌ |
| `green600` 텍스트 on 흰 배경 | 3.10:1 | ❌ |
| `blue500`(링크) on 흰 배경 | 3.54:1 | ❌ |
| `red`(에러) on 흰 배경 | 3.53:1 | ❌ |
| `green600` on `green50` (배지) | 2.87:1 | ❌ |

이 문서 초안은 "버튼 라벨은 `green600` 배경을 쓰면 AA 를 넘는다"고 적었지만,
실제로는 3.10:1 로 **넘지 못한다.** 계산해 보고 정정했다.

### 두 가지 대응

**1. 버튼은 밝은 그린 배경 + 어두운 잉크**

`green500` 을 어둡게 바꾸는 대신 텍스트를 어둡게 했다. 키컬러의 밝은 인상을 살리면서
`#181A1B` 조합으로 **9.61:1** 을 얻는다. hover(`green600`)도 5.64:1 로 통과한다.

**2. 텍스트용 파생 shade 추가**

원본에 없던 값이다. 각각 흰 배경(또는 해당 연한 배경)에서 4.5:1 을 겨우 넘는
가장 밝은 값으로 잡았다 — 필요 이상으로 어둡게 만들지 않기 위해.

| 파생 토큰 | HEX | 유래 | 용도 |
| --- | --- | --- | --- |
| `--raw-green-700` | `#1C7D4A` | green600 을 어둡게 | 연한 배경 위 브랜드 텍스트, 목(木) 배지 |
| `--raw-blue-700` | `#296ACC` | blue500 | 링크, 수(水) 배지 |
| `--raw-red-700` | `#C92E3A` | red | 에러 텍스트, 화(火) 배지 |
| `--raw-yellow-700` | `#8A6F18` | starYellow | 경고 텍스트, 토(土) 배지 |
| `--raw-gray-450` | `#8F959A` | gray400 | 폼 컨트롤 경계 (3:1 확보) |
| `--raw-red-100` / `yellow-100` | `#FFE7E9` / `#FEF8E6` | 각 색 + 흰색 88% | 상태 배경 |

`gray600` 은 여전히 정의하지 않았다. 쓸 자리가 없었다.

### 오행 배지

전통 색 대응(목=녹, 화=적, 토=황, 금=백, 수=흑/청)을 팔레트 안에서 표현했다.
각 색을 흰색과 88% 섞어 배경을 만들고, 그 배경에서 4.5:1 을 넘는 전경을 계산했다.

| 오행 | 배경 | 전경 | 대비비 |
| --- | --- | --- | --- |
| 목 | `#E5F4EC` | `#1C7D4A` | 4.53:1 |
| 화 | `#FFE7E9` | `#C92E3A` | 4.54:1 |
| 토 | `#FEF8E6` | `#8A6F18` | 4.53:1 |
| 금 | `#EDEDED` | `#6D676C` | 4.71:1 |
| 수 | `#E7F0FF` | `#296ACC` | 4.54:1 |

TASK-10 의 OG 이미지도 이 토큰을 쓴다. 브랜드 그린과 목(木) 배지가 같은 계열이므로,
**브랜드 그린 채움(`bg-brand`)은 주 액션에만** 쓰고 배지는 연한 톤으로 유지한다.

### 다크 모드는 도입하지 않았다

팔레트가 밝은 톤(거의 흰 배경, 밝은 키컬러) 전제로 설계됐고, 지금 단계에서 두 벌을
유지·검증할 이유가 없다. `color-scheme: light` 로 고정해 폼 컨트롤 반전을 막았다.
필요해지면 시맨틱 토큰만 다시 정의하면 되도록 2층 구조를 열어 뒀다.
(TASK-11 의 중복 항목은 이 결정으로 삭제했다.)

### 쓰지 않은 값

- **페이지 배경 그라디언트** — `--raw-white-warm: #FDFFFB` 단색만 썼다. 원본도 거의 흰색이라
  그라디언트의 시각 효과가 거의 없었다. 히어로 영역을 만들 때 다시 고려한다.
- `blue500`, `red`, `starYellow` 원본값 — 아이콘·채움용으로 남겨 뒀고 텍스트에는 파생값을 쓴다.
