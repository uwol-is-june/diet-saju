# `public/dasii/` — 다시(dasii) 브랜드 자산

데스크톱 좌측 패널(`components/AppPanel.tsx`)이 쓰는 파일들이다.

**핫링크하지 않는다.** 자산을 받아 여기 커밋하고 우리 도메인에서 서빙한다 — 방문자
브라우저가 제3자에 요청을 보내면 `app/privacy/page.tsx` 4·5항("외부 도구를 전혀 쓰지
않습니다")이 거짓이 된다. 파일을 URL 로 바꾸는 순간 그 두 항을 같은 커밋에서 고쳐야 한다.

## 워드마크만 파일이고 문양은 벡터다 (TASK-83)

문양은 `components/AppPanel.tsx` 가 `docs/icon.html` 과 **같은 좌표**로 그린다 (TASK-76 에서
원본 55×55 마스크와 대조해 역산한 실측값). 원본의 통짜 로고(`/images/logo.png`)는
**187×55 한 벌**이라 문양이 44px 로 그려지는 자리에서 DPR 2·3 이면 뭉갠다 — 그래서 문양은
벡터로 두고 글자만 고해상도 원본에서 받았다.

`logo_text.png` 은 원본 906×404 를 **360×161** 로 줄인 것이다. 화면 표시 크기가 87×39 이므로
DPR 3(261×117)까지 덮는다. 줄이는 데 의존성을 쓰지 않았다 — 헤드리스 크로미움 캔버스로
다시 그렸다(`scripts/lib/cdp.mjs` 를 쓰는 일회성 작업이었고, 다시 할 일이 생기면 그때
같은 방법으로 한다).

## 문양 비율은 원본 통짜 로고에서 잰 값이다

`logo.png` 의 불투명 픽셀 경계를 열 단위로 훑어 얻었다 — 문양 55 · 사이 21 · 글자 109
(글자 높이는 원본 비율로 48.6). 문양 높이를 1 로 두면 **사이 0.38 · 글자 폭 1.98 ·
글자 높이 0.88** 이다. **눈대중으로 고치지 말 것.**
